# April

**พ่อบ้าน AI ส่วนตัวแบบ JARVIS / FRIDAY** สุภาพ รู้ใจ ทำงานให้เสร็จด้วยเครื่องมือแทนการถามกลับ และคอยเตือนหรือสรุปงานให้เองโดยไม่ต้องรอให้ถาม

- **มองเห็นผ่านกล้อง Mac**: ตรวจจับคน/ใบหน้า/สัตว์/การเคลื่อนไหวบนเครื่องแบบเรียลไทม์ ให้ LLM ดูภาพจริงเมื่อถาม
  และเฝ้าดูสิ่งที่สั่งไว้แล้วบอกเอง (ดู "การมองเห็น")
- **โมเดลในเครื่อง 1 ตัว** (Ollama · ค่าเริ่มต้น `qwen3.5:4b`) ใช้ได้เสมอแม้ไม่มีเน็ต และเป็นตัวสำรองสุดท้าย
- **โมเดล cloud หลายตัว**: Claude Opus / Sonnet / Haiku, gpt-oss (Ollama Cloud), ChatGPT, Gemini
  ถ้า cloud ล่ม ไม่มีคีย์ หรือเกินโควตา จะสลับไปตัวถัดไปเองในคำขอเดียวกัน
- **ไม่มีระบบปลั๊กอิน** เครื่องมือทั้งหมดอยู่ในแกนของ April

พัฒนาต่อจาก [Envy](../Agent) แต่เขียนแกนใหม่: Envy แตกงานเป็น DAG ของ agent หลายตัว
(planner → decomposer → dispatcher → writer) ส่วน April ใช้ **agent loop วงเดียว** ที่ให้โมเดลวางแผนและเรียกเครื่องมือเอง
(native tool calling ทุก provider) ทำให้โค้ดเล็กกว่ามากและต่อยอดง่าย

## เริ่มใช้

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -e ".[dev]"
cp .env.example .env          # ใส่ชื่อ, คีย์ cloud (ไม่ใส่ = ใช้โมเดลในเครื่องอย่างเดียว)
ollama pull qwen3.5:4b

.venv/bin/python -m april chat        # คุยในเทอร์มินัล
.venv/bin/python -m april serve       # HTTP API ที่ http://127.0.0.1:8100
.venv/bin/python -m april models      # ดูว่าโมเดลไหนพร้อมใช้
```

## แอป Mac

ดาวน์โหลด `April-<รุ่น>.dmg` จาก [Releases](https://github.com/AImunich20/April/releases) แล้วลากไปไว้ที่ Applications

โดยไม่ต้องใช้ Homebrew หรือรหัสผ่านเครื่อง

### ใช้งาน April = เรียกแบบ Siri ที่รอยบากจอ (Dynamic Island)

- กด **⌥ Space** (เปลี่ยนได้ในแท็บ "เสียง") จากแอปไหนก็ได้ หรือพูดว่า **"April"** -> เสียง "ติ๊ง" แล้วพื้นที่ดำขยายออกจากรอยบากจอ
  แบบ Dynamic Island และฟังทันที -> April ตอบด้วยเสียงไทย -> รอฟังคำถามต่อ 5 วินาที -> เงียบ = หดกลับเข้ารอยบาก
- **ไม่มีตัวอักษร** มีแต่แอนิเมชันสีเหลืองบนพื้นดำ: หูซ้าย = ลูกแก้วอนุภาค · หูขวา = สถานะ (ฟัง: วงตามเสียงไมค์ ·
  คิด: วงหมุนสีส้ม · พูด: แท่งอีควอไลเซอร์ · ผิดพลาด: จุดแดง) · แถบใต้รอยบาก = คลื่นเสียง
- แตะเกาะ = เริ่ม/หยุดฟัง หรือพูดแทรก · แตะ 2 ครั้ง / Esc = ปิด · คำตอบเต็มดูย้อนหลังได้ในแท็บ "งาน" ของศูนย์ควบคุม
- จอที่ไม่มีรอยบาก: เกาะเป็นแคปซูลดำห้อยจากกลางขอบบนจอ · ไม่ดึงโฟกัสจากแอปที่ใช้อยู่ · ใช้ได้ทุก Space และแอปเต็มจอ
- เรียกแล้ว April เริ่มโหลดโมเดลในเครื่องขึ้น RAM ทันทีระหว่างที่คุณพูด · คำปลุก ("ฮัลโหล April …") ถูกตัดออกก่อนส่ง
- เรียกด้วยเสียง "April" ฟังตลอดเวลาแบบถอดเสียง **บนเครื่องเท่านั้น** — เครื่องที่ทำไม่ได้จะไม่เปิดให้ใช้ (เสียงในห้องไม่ออกนอกเครื่อง)
- ไม่ได้เรียกเกิน 5 นาที = เริ่มบทสนทนาใหม่ (ความจำเรื่องคุณยังอยู่ครบ)

**การเชื่อมต่อ** (API, token, การสั่งงานเครื่อง, ไฟล์) · **อัปเดต**

  - รายการทุกรุ่นพร้อมรายละเอียด: กดติดตั้งรุ่นใดก็ได้ **รวมถึงย้อนกลับไปรุ่นเก่า** (ย้อนแล้วจะตรึงรุ่นไว้ไม่ให้อัปเดตเองทับ จนกว่าจะเลิกตรึง)

### การมองเห็น: กล้องคือตาของ April

แอป Mac เปิดกล้องแล้วตรวจจับ **บนเครื่อง** ทุก ~0.2 วินาที (`Apple/Sources/Vision.swift`) — งานเบาและถี่อยู่บนเครื่อง
ส่วน LLM ดูภาพจริงเฉพาะตอนจำเป็น (`april/vision.py`)

| ชั้น | ทำอะไร | ที่ไหน |
|---|---|---|
| การเคลื่อนไหว | เทียบเฟรม (ย่อเป็นขาวดำ 32×18, หักแสงที่เปลี่ยนทั้งภาพ) ~10 ครั้ง/วิ | บนเครื่อง |
| ตรวจจับ | คน ใบหน้า แมว/สุนัข (Apple Vision) ~5 ครั้ง/วิ · ป้ายฉาก ~1,300 แบบ ทุก 2 วิ | บนเครื่อง |
| วัตถุทุกชนิด (ไม่บังคับ) | วางโมเดล Core ML แบบ object detection (เช่น YOLO) ใน `data/vision/` | บนเครื่อง |
| มอง/เฝ้าดู/สรุปเหตุการณ์ | LLM ดูภาพจริง + ผลตรวจจับ | `APRIL_VISION_MODEL` (ค่าเริ่มต้นในเครื่อง) |

- **โหมด** (แท็บ "การมองเห็น" หรือเมนูบน menu bar): *ปิด* · *เมื่อต้องมอง* (ค่าเริ่มต้น — กล้องเปิดเองตอน April ต้องมองหรือกำลังเฝ้าดู แล้วปิดเอง)
  · *เปิดตลอด* (เรียลไทม์: รู้ว่าคนมา/ไป มีอะไรขยับตอนไม่อยู่ เห็นสัตว์ ทักทาย + สรุปสิ่งที่พลาดเมื่อกลับมา)
- **ถามได้เลย**: "เห็นอะไรอยู่" "ผมถืออะไร" "เสื้อผมสีอะไร" -> `look` · "บอกด้วยถ้าแมวขึ้นโต๊ะ" -> `watch_for`
  (เจอแล้ว April เด้งเกาะออกมาพูดเอง + แจ้งเตือน) · "เมื่อกี้มีใครมาไหม" -> `vision_events`
- **แท็บการมองเห็น**: ภาพสดพร้อม HUD (กรอบตรวจจับ, แถบการเคลื่อนไหว, ฉาก), สิ่งที่เฝ้าดู, เหตุการณ์ล่าสุด, ค่าการแจ้ง
- **ความเป็นส่วนตัว**: ภาพอยู่ใน RAM เท่านั้น ไม่เขียนดิสก์ ไม่เก็บในประวัติแชท ไม่มี API ให้ดึงภาพออก ·
  งานเบื้องหลังใช้โมเดลในเครื่องเป็นค่าเริ่มต้น · `APRIL_VISION_CLOUD=false` = ภาพกล้องไม่ไป cloud เลย ·
  ไฟเขียวข้างกล้องติดทุกครั้งที่เปิด และไอคอนบน menu bar เป็นรูปตา
- โมเดลที่มองภาพไม่ได้ (`vision: false` ใน `models.yaml` เช่น gpt-oss) ถูกตัดภาพออกอัตโนมัติ ได้แค่ผลตรวจจับเป็นข้อความ
- ตรวจวัตถุได้ทุกชนิด: `pip install ultralytics && yolo export model=yolo11n.pt format=coreml nms=True`
  แล้ววาง `.mlpackage` ไว้ใน `data/vision/` -> กด "โหลดใหม่" ในแท็บ

**ตรวจตัวเลขก่อนส่ง** (เปิดเสมอ): คำตอบต้องมีตัวเลขตรงกับผลการคำนวณล่าสุด ไม่ตรง = ให้เขียนใหม่ 1 ครั้งพร้อมตัวเลขที่ถูก
(วัดจริง: โมเดล 4B ในโหมดเสียงเคยแปลง 67,500 เป็นคำอ่านผิดเป็น "หกหมื่นเจ็ดพันหกล้าน")

**คิดก่อนตอบ ตรวจก่อนส่ง** (`APRIL_CHECKLIST_ENABLED=true`): ย่อมาจาก Envy 2.3.1 แตกคำขอที่มีเงื่อนไขเป็นเช็กลิสต์
ตรวจคำตอบทีละข้อ แล้วแก้ 1 ครั้งถ้าไม่ผ่าน

```
│   ├── prompts.py       บุคลิกพ่อบ้าน (system prompt คงที่ เพื่อให้ prompt cache ทำงาน)

│   ├── catalog.py       อ่าน models.yaml (local 1 + cloud หลายตัว)
│   ├── router.py        เลือกโมเดล + สำรองอัตโนมัติ + พักตัวที่คีย์ผิด/เกินโควตา
│   ├── ollama.py        Ollama ในเครื่อง + Ollama Cloud
│   ├── anthropic_provider.py   Claude (SDK ทางการ, adaptive thinking, server-side fallback)
│   └── openai_compat.py ChatGPT / Gemini / เจ้าอื่นที่ใช้ API แบบ OpenAI
├── tools/               ทะเบียนเครื่องมือ + เครื่องมือในตัว
├── memory/store.py      SQLite: แชท ความจำ ตัวเตือน ประกาศ
├── scheduler.py         งานเชิงรุก
├── vision.py            การมองเห็น: รับผลตรวจจับ/ภาพจากแอป, เฝ้าดู, สรุปเหตุการณ์ (tools/vision.py = เครื่องมือ)
├── server.py            FastAPI (SSE)
├── cli.py               python -m april …
└── models.yaml          แค็ตตาล็อกโมเดล
```

## HTTP API

| | |
|---|---|
| `POST /chat` | `{message, session_id?, model?, images?}` → SSE: `session` `model` `thinking` `token` `tool_call` `tool_result` `fallback` `revision` `error` `done` |
| `POST /chat/sync` | เหมือนกันแต่คืน JSON ตอนจบ |
| `GET /models` · `GET /health` | สถานะโมเดล / Ollama |
| `GET /sessions` · `GET/DELETE /sessions/{id}` | ประวัติแชท |
| `GET /notes` · `DELETE /notes/{id}` | ความจำ |
| `GET /reminders` · `GET /announcements?unread=true` · `POST /briefing` | งานเชิงรุก |
| `/api/vision/*` | การมองเห็น: แอปส่งผลตรวจจับ + ภาพ (`frame`), เหตุการณ์ (`event`), รอคำขอเปิดกล้อง (`demand`) |
| `/api/*` | ข้อมูลของศูนย์ควบคุมในแอป Mac (`april/control_api.py`) |

เปิดให้เครื่องอื่นเข้าได้ (`APRIL_HOST=0.0.0.0`) ต้องตั้ง `APRIL_API_TOKEN` ด้วย

## ความปลอดภัย

- ไม่มีเครื่องมือรันคำสั่ง shell — ทุกอย่างที่ทำกับเครื่องผ่านคำสั่งที่กำหนดไว้แล้ว (`open -a`, `open <url>`, `osascript` แบบส่ง argv)
- `read_webpage` ไม่เปิดที่อยู่ในเครื่องหรือวง LAN (กัน SSRF) และตรวจปลายทางทุกครั้งที่ redirect
- `calculate` ประเมินผลเองจาก AST ไม่ใช้ `eval` และกันตัวเลขยกกำลังหรือ factorial ที่ใหญ่จนเครื่องค้าง
- ปิดเครื่องมือที่สั่งงานเครื่องทั้งหมดได้ด้วย `APRIL_ALLOW_ACTIONS=false`
- argument ทุกตัวจากโมเดลถูกตรวจกับ schema ก่อนรันเสมอ
